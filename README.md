## 🎯 Sobre mí

QA Automation con **3 años de experiencia** en pruebas funcionales y automatizadas end-to-end.

Mi trabajo no se queda en la interfaz: analizo requerimientos funcionales, redacto criterios de aceptación en **notación Gherkin** y diseño casos de prueba con trazabilidad completa hasta el reporte de incidencias. Bajo hasta la capa de datos para validar consistencia, migraciones e integridad, porque ahí es donde un error deja de ser cosmético y se vuelve un problema de confianza.

```
Requerimiento → Criterios de aceptación → Casos de prueba → Ejecución → Incidencias → Cierre
```
