## 🎯 Sobre mí

QA con **más de 3 años de experiencia** en pruebas funcionales y automatizadas end-to-end sobre plataformas fintech de trading y opciones binarias.

Mi trabajo no se queda en la interfaz: analizo requerimientos, redacto historias de usuario y criterios de aceptación en **Gherkin** (`Feature`, `Scenario`, `Given`, `When`, `Then`, `And`) y diseño casos de prueba con escenarios positivos, negativos y de valores límite, trazables hasta el reporte de defectos. Bajo hasta la capa de datos para validar consistencia, migraciones e integridad, porque ahí es donde un error deja de ser cosmético y se vuelve un problema de confianza.

```
Requerimiento → Criterios de aceptación → Casos de prueba → Ejecución → Defectos → Cierre
```

## 💼 Experiencia

> Diseñé e implementé desde cero el framework de automatización E2E con Playwright y TypeScript sobre los flujos críticos de negocio, con Page Object Model y selectores estables, y luego migré los flujos a Selenium con Java y Cucumber. Automaticé la regresión de los flujos de mayor riesgo, gestioné los scripts en GitHub con ramas, commits y pull requests, y configuré el CI/CD para ejecutarlos en cada push en los ambientes dev, QA y prod. Documenté requisitos y pruebas en Gherkin, validé APIs con Postman y datos con SQL y MongoDB, y concilié saldos entre un procesador de pagos y la plataforma.

**GlobalS1** — Analista de Calidad de Software · `febrero 2023 – febrero 2024`

> Revisé el módulo de torneos y rankings de una plataforma de trading, verificando en la base de datos con SQL que los resultados, las posiciones y los premios fueran correctos. Analicé requerimientos, redacté criterios de aceptación en Gherkin y diseñé casos de prueba. Ejecuté pruebas funcionales, de integración, de sistema, de regresión, smoke, sanity y exploratorias, y gestioné los defectos en Jira bajo Scrum.
